# 🏎️ Mario Kart Terminal Simulator

Simulador de corridas inspirado em Mario Kart, rodando 100% no terminal com Node.js!

### Para jogar

```bash
unzip mariokart-terminal.zip
cd mariokart
node index.js
```

## 🚀 Como Executar

```bash
node index.js
```

## 🎮 Controles

| Tecla | Ação |
|-------|------|
| `W` | Acelerar |
| `A` | Virar esquerda / Desviar |
| `D` | Virar direita / Desviar |
| `R` | Drift (acumule 3x para turbo!) |
| `F` ou `Espaço` | Usar item |
| `Q` | Sair da corrida |

## 💡 Dicas

- Quanto pior sua posição, melhor o item recebido!
- Drift 3x consecutivos = Turbo extra poderoso
- 🔶 Boost Pads no chão = Turbo automático
- Itens de ataque são mais eficazes quando em posições baixas
